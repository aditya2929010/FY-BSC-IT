# GPA Calculator Using Python

## Project Description

The GPA Calculator is a beginner-friendly Python-based application designed to calculate a student's Grade Point Average (GPA). It allows users to enter their subject grades and corresponding credit values to calculate their GPA easily and accurately.

This project demonstrates the use of basic Python programming concepts, mathematical operations, user input, and conditional statements.

## Features

- Enter subject names and grades.
- Input credits for individual subjects.
- Calculate GPA automatically.
- Display the final GPA.
- Simple and user-friendly interface.
- Handles invalid inputs.

## Technologies Used

- **Programming Language:** Python
- **Concepts:** Variables, Loops, Conditional Statements, Functions, and Arithmetic Operations.
